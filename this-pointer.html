Summary

01 · What is this?

  • this is a pointer to the object that called the member function.
  • It is passed automatically to every non-static member function.
  • It can only be used inside non-static member functions — never outside the class.

02 · Member vs parameter

  • When a parameter has the same name as a data member, this->grade = grade; assigns the member.
  • Without it, grade = grade; assigns the parameter to itself and the member stays unchanged — a logical error.
  • Alternative: the initialiser list Student(int grade) : grade(grade) { } — often preferred.

03 · Returning the object

  • return *this; returns the current object, e.g. from Student& test().
  • Used as Student s1 = s.test();

04 · The object's address

  • cout << this; prints the address of the object that called the function.

05 · Static vs const functions

  • A static member function belongs to the class, not to an object, so it has no this.
  • A const member function works on a specific object (it has a hidden this) and promises not to modify its data members.
  • A member function can't be both: const needs an object to protect, and static has none.

Extra Notes · beyond the PDF

Good to know

  • *this is the object itself; this is its address.
  • Cascading works because each setter returns *this by reference: s.setName("Sara").setGrade(95);
  • In a const member function, this points to a const object, so it can't be used to change data members.

Common mistakes

  • Returning Student by value from a setter — the chain then changes a temporary copy, not the original object.
  • Writing this.grade — this is a pointer, so use this->grade or (*this).grade.
  • Using this inside a static member function — compile error.

Where you'll see it again

  • Self-assignment check in operator=: if (this != &other).
  • Operators like += and prefix ++ end with return *this;
