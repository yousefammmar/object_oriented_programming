Key Concepts

  • Declared inside the class with friend
  • Accesses private and protected members
  • Not a member — no this pointer
  • Called as f(obj), not obj.f()
  • One friend shared by two classes
  • Forward declaration of the second class
This page is a short summary. The full notes are in Friend Function.pdf on Google Drive.

Summary

01 · What is a friend function?

  • A function that is not a member of the class but can access its private and protected members.
  • Declared inside the class with the friend keyword, and defined outside like a normal function.
  • It isn't called on an object, so it has no this pointer. Often used for operator overloading.

02 · Example

  • friend void printGrade(const Student& s); inside Student — the definition reads s.grade directly.
  • Called as printGrade(s1);, not s1.printGrade();

03 · Friend of several classes

  • One function can be a friend of more than one class, reading each one's private data while belonging to none.
  • Both classes declare friend void showSum(const ClassA& a, const ClassB& b); and it is called as showSum(objA, objB);
  • Forward-declare the second class before the first one uses it: class ClassB;

Extra Notes · beyond the PDF

Rules of friendship

  • Friendship is granted, not taken — only the class itself can declare its friends.
  • It isn't mutual: if A is a friend of B, B is not automatically a friend of A.
  • It isn't inherited and isn't transitive — a friend of a friend is not a friend.
  • The friend declaration can go in the public or private part; it means the same thing.

Friend classes

  • friend class Auditor; makes every member function of Auditor a friend.
  • Useful when two classes are tightly linked, e.g. a list and its node class.

When to use it

  • Prefer member functions and getters first; every friend weakens encapsulation.
  • Good uses: a function that needs private data from two classes, and operators like << whose left operand isn't your class.
